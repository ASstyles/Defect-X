# **App Name**: EdgeVision Pro

## Core Features:

- Live Inspection Hub: A real-time monitoring interface that displays industrial camera feeds with YOLOv8-powered defect overlays.
- Gemini Analysis Tool: An AI reasoning tool that performs root cause analysis and assigns detailed quality scores based on detected surface irregularities.
- Defect Severity Engine: Classifies defects into Critical, High, Medium, or Low severity based on AI evaluation of structural integrity.
- Historical Performance Database: Centralized storage for defect logs and inspection history using a PostgreSQL database to track machine and shift performance.
- Digital Twin Dashboard: A visual status grid showing machine health, warning states, and real-time production line analytics.
- Predictive Maintenance Forecasts: Leverages historical trends as a tool to predict machine wear and suggest proactive maintenance schedules.
- Factory Expert Chatbot: An intelligent conversational interface allowing operators to ask the expert AI assistant questions about compliance and safe operation.

## Style Guidelines:

- A dark scheme using a Deep Indigo primary (#3b62f2) to represent industrial intelligence, contrasted with an Deep Navy background (#0d1017).
- An Analogous Cyan accent (#0ea5e9) for critical status indicators and high-importance UI elements.
- A technical font pairing: 'Space Grotesk' for high-precision headlines and 'Inter' for objective, readable data tables and logs.
- Precision line icons with 1px stroke weights, reflecting technical schematics and CAD-inspired aesthetics.
- A dashboard-first grid layout that maximizes screen real estate for concurrent camera feeds and live data telemetry.
- Low-latency micro-interactions such as subtle pulse effects on defect hotspots to alert operators without causing distraction.
